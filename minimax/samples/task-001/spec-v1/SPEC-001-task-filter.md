# SPEC-001 任务筛选规格

- 版本：v1
- 状态：已批准
- 适用范围：`taskboard.service.filter_tasks`
- 最后修改：2026-10-20

## R1 状态筛选

`status` 取 `"all"`、`"open"`、`"done"` 三者之一。取其他值时抛出 `ValueError`。

## R2 标签筛选

`tag` 为单个标签字符串。筛选后只保留 `tags` 中包含该标签的任务。

匹配规则：**区分大小写**，按字符串完全相等比较。

## R3 最低优先级

`min_priority` 为最低优先级（含）。为 `None` 时不按优先级筛选。

## R4 条件交集

`status`、`tag`、`min_priority` 同时给出时，结果须同时满足全部条件。

## R5 顺序保持

筛选结果的任务顺序必须与入参顺序一致，不得重排。
